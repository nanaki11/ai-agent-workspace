# 成長戦略立案

## 手順
1. **起点を確認する**：environment-analysis の戦略課題と KSF。なければ先に作る
2. **事業ポートフォリオを評価する**
   - PPM（市場成長率×相対シェア）または GEマトリクス（市場の魅力度×自社の競争力）
   - 事業ごとの方向性：拡大／維持／収穫／撤退
3. **成長の方向を洗い出す（アンゾフ）**

   | | 既存製品 | 新製品 |
   |---|---|---|
   | 既存市場 | 市場浸透 | 製品開発 |
   | 新市場 | 市場開拓 | 多角化 |

4. **戦略オプションを作る**
   - 方向ごとに実現手段を考える：自前（Build）／買収（Buy）／提携（Partner）
   - オプションは3〜5個。現状維持（何もしない）を比較対象として必ず入れる
5. **評価する**（quantitative-analysis の評価マトリクス）
   - 評価軸の例：市場の魅力度、自社の強みとの適合、収益性（NPV）、実現性（必要な資源・期間）、リスク
6. **不確実性に備える（シナリオプランニング）**
   - 影響が大きく不確実な要因を2つ選び、2×2で4つのシナリオを作る
   - どのシナリオでも有効な打ち手（ノーリグレット）と、シナリオ別の打ち手を分ける
   - シナリオの兆候を見る指標（早期警戒指標）を決める
7. **選んで論拠を示す**：採用案、捨てた案とその理由、前提条件、撤退基準

## ビジネスモデルの設計
ビジネスモデルキャンバスの9要素で書く：顧客セグメント／提供価値／チャネル／顧客との関係／収益の流れ／主要な資源／主要な活動／主要なパートナー／コスト構造。収益モデル（売り切り、サブスクリプション、従量課金、手数料、広告）を明示する。

## 新規事業
- リーンキャンバスで、顧客・課題・解決策・独自の価値・収益を書く
- 検証すべき仮説を「顧客がいるか → 課題は本当か → 解決策は受け入れられるか → お金を払うか」の順に並べる
- PoC計画：検証する仮説、方法、期間、合格基準、費用

## M&A・アライアンス
- ターゲットの選定基準（必須条件／望ましい条件）とロングリスト → ショートリスト
- シナジー：売上シナジー（クロスセル、販路）とコストシナジー（統合、調達）を分けて試算する。売上シナジーは割り引いて見る
- 主なリスク：のれんの減損、人材流出、システム統合、文化の違い
- PMIの方針：統合の度合い（独立運営〜完全統合）、最初の100日で行うこと
