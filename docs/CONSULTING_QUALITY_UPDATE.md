# Consulting Toolkit 品質改善（2026-10-30）

## 変更

- 既存21スキルを維持し、各専門領域の追加検証と共通の実行契約を追加。
- 共通規約の正本は `common/rules/consulting-delivery-standard.md`。各スキルの参照版は `generate.py` が生成する。
- 簡易相談／分析ドラフト／顧客提出用で作業量を調整。判断事項、主張と根拠、仮定、要件、決定、引き継ぎを管理。
- 顧客提出用は提出可／要修正／未検証で判定。重大指摘や必須検証の未実施を残したまま提出可にしない。
- ストーリーとスライドのタイトル・リード文方式を統一。調査情報の鮮度を一律3年から情報の更新頻度・調査目的に変更。
- 検索ツールの固定指定と事実ラベルの欠落を解消。外部スライド資源は取得失敗や版違いを無視して実行しない。
- ChatGPT向け配布スクリプトを追加。21スキルの原文と資源、4役割の原文、共通ルール、ソースコミット・SHA-256を同梱。原本の要約は行わない。
- インタビュー、合意形成、効果実現は既存の関連スキルに補強し、スキル数は増やしていない。

## 検証

- `python3 scripts/validate.py`：スキル21・役割4、エラー0。
- `python3 -m unittest discover -s tests -v`：7件。ChatGPT/Claude配布物の原本バイト一致、役割・規約の同梱、規約の同期ずれ検出、ZIP内容一致、配布形式移行時の設定保持と未対応項目の検出。
- `bash scripts/scan_secrets.sh`：正規表現検査で検出なし。gitleaks・detect-secretsは未インストールで未実施。
- `git diff --check`：空白エラーなし。
- 独立した新規エージェントで、国内データ保管Must未確認の安価なSaaSを推奨する仮想案件を実行。Must未確認と採点根拠欠損を検出し、採用保留・ドラフト要修正と判定。既知費用をTCOと混同せず、確認担当を未合意の案として提示した。

## 制約

この検証は全業務の品質や実案件での工数削減を保証しない。外部スライドリポジトリ、レンダリングツール、実行環境の実動作は未検証。
ChatGPTのプラグイン更新・公開はGitHubへの反映と別操作。本変更は配布物の生成を可能にするが、自動でインストール済みプラグインを書き換えない。
外部スライド資源は同梱せず、固定コミットと依存関係を記録する。
