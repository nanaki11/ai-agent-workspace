# ストーリーライン構築

## 手順
1. **読み手と目的を決める**：誰が（役職）、読んで何を決める／何をするか。持ち時間と枚数
2. **メインメッセージを1文にする**：「〜すべきである。なぜなら〜」
3. **SCQAで導入を作る**
   - S（状況）：読み手が同意できる事実
   - C（複雑化）：問題や変化
   - Q（問い）：だから何を考えるべきか
   - A（答え）：メインメッセージ
4. **ピラミッドを組む**
   - メインメッセージの下に根拠を3つ前後（MECE）
   - 各根拠の下に事実・分析
   - 帰納（事実を並べる）か演繹（大前提→小前提→結論）かを決める
5. **空パック（スライド骨子）を作る**
   - 1スライド1メッセージ。タイトルは60字以内で、言い切りの文にする
   - タイトルだけを順に読んでストーリーが通ること（縦の論理）
   - 各スライドの本文がタイトルを裏付けていること（横の論理）
6. **エグゼクティブサマリーを書く**：結論 → 根拠3つ → 次のアクション（期限と責任者）を1枚に

## 空パックのフォーマット
```
## 読み手／目的／枚数
## メインメッセージ
## SCQA
## スライド骨子
| No | セクション | メッセージ（タイトル） | 本文の中身（チャート種類・データ） | データの状態 |
| 1 | サマリー | … | 箇条書き3点 | – |
| 2 | 現状 | … | 縦棒：売上推移 2020-2025 | 取得済（有報） |
```
- データの状態：取得済／要調査／仮置き

## チャートの選び方
| 伝えたいこと | チャート |
|---|---|
| 時系列の推移 | 折れ線、縦棒 |
| 構成比 | 積み上げ棒、100%積み上げ棒 |
| 項目の比較・ランキング | 横棒 |
| 増減の内訳 | ウォーターフォール |
| 2つの軸での位置づけ | 2×2マトリクス、散布図 |
| プロセス・構造・システム | フロー図、構成図（drawio-diagram） |

## スライドにする
- 骨子が固まったら consulting-pptx-skill でスライドを作る
- 業務フローやシステム構成図などの複雑な図は drawio-diagram で作り、PNG にしてスライドに貼る

## チェック
- タイトルが「〜について」「〜の現状」のような見出しになっていない
- 1枚にメッセージが2つ入っていない
- 結論が最初にある
