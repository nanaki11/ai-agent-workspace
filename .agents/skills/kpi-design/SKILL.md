# KPI設計

## 手順
1. **KGI を決める**：最終的に達成したい結果を1〜2個（例：営業利益率 10%）
2. **KPIツリーに分解する**
   - 掛け算・足し算で分解する（例：売上 ＝ 商談数 × 受注率 × 平均単価）
   - 分解は3〜4階層まで。末端は、現場が行動で動かせる指標にする
3. **KPI を選ぶ**（すべてを KPI にしない）
   - KGI への影響が大きく、現場が動かせて、データが取れるものを、1つの階層で5〜7個まで
   - 遅行指標（結果）と先行指標（結果より先に動く指標）を組み合わせる
4. **定義書を作る**（解釈がぶれないように）
5. **目標値を決める**：過去の実績、ベンチマーク、KGI からの逆算の3つで確かめる
6. **モニタリングを設計する**：頻度、会議体、ダッシュボード、閾値を超えたときの対応

## チェック
- [ ] SMART になっている（具体的・測れる・達成可能・KGIと関係がある・期限がある）
- [ ] KPI の改善が KGI の改善につながる
- [ ] 副作用がない（数字だけ良くする行動を招かない。例：解約率だけ追うと新規獲得を絞る）。必要なら対になる指標を置く
- [ ] データを手作業で集めなければならない KPI は、集める手間に見合うか

- ダッシュボードの構成案（どの KPI を、どの粒度で、誰が見るか）
