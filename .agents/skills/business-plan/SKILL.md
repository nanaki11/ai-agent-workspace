# 中期経営計画・事業計画

## 計画の構造（上から下へ一貫させる）
```
ビジョン（10年後の姿）
 └ 中期の目標（3〜5年のKGI：売上、営業利益率、ROICなど）
    └ 基本戦略（3〜5本の柱）
       └ 重点施策（柱ごとに2〜4個。KPI・責任部門・投資額）
          └ ロードマップ（年度・四半期ごと）
             └ 収支計画（PL、投資、人員）
```

## 手順
1. **振り返り**：前回の計画の目標と実績の差、その原因
2. **前提を確認する**：environment-analysis（環境認識）と growth-strategy（戦略の方向性）を受ける
3. **目標を決める**
   - 成り行き（何もしなかった場合）の予測と、目標とのギャップを示す
   - ギャップを施策でどう埋めるかを、ウォーターフォールで示す
4. **施策を具体化する**：施策ごとに目的、KPIと目標値、責任部門、開始・完了時期、投資額・費用、期待効果
5. **ロードマップを作る**：依存関係（Aが終わらないとBが始められない）と、年度ごとのマイルストーン
6. **収支計画を作る**（quantitative-analysis）
   - 売上はドライバーに分解して積み上げる（例：顧客数×単価、店舗数×店舗あたり売上）
   - 費用は変動費と固定費に分ける。施策ごとの追加費用・投資を足す
   - PL（3〜5年）、設備投資・減価償却、人員計画、主要な財務指標
   - 悲観／標準／楽観の3ケース
7. **管理の仕組み**：KPIのモニタリング頻度、見直しの条件（kpi-design）

## 整合性チェック
- [ ] すべての施策が、どれかの戦略の柱につながっている
- [ ] 施策の効果の合計で、目標とのギャップが埋まっている
- [ ] 投資額の合計が、キャッシュフロー上で無理がない
- [ ] 人員計画と施策に必要な人員が一致する
- [ ] 1年目の計画が、今年度の予算と矛盾しない

## 出力フォーマット
```
## 計画サマリー（目標数値と戦略の柱を1枚に）
## 前回計画の振り返り
## 環境認識と戦略の方向性
## 目標（KGI）と成り行きとのギャップ
## 戦略の柱と重点施策
| 柱 | 施策 | KPI（目標値） | 責任部門 | 時期 | 投資額 | 効果 |
## ロードマップ
## 収支計画（3ケース）
## リスクと対応
```
