# MECEレビューと6シナリオ

基準日: 2026-11-01 JST / 版: 1.4.1
方法: 2担当が同じ現行原文を独立レビューし、親が照合・統合。修正後に別担当がルーターを入口として6依頼へ回答。外部操作・実装なし。

|依頼|観測した担当と成果物|判定|
|---|---|---|
|標準内のボタン・フォーム変更|frontendが領域内で完結。IT・PMOの経由を必須にしない|合格|
|横断認証・非機能配分と同等の画面/API/基盤改修|ITが暫定統合、各engineerの成果物ownerを保持|合格|
|データ移行・基盤復元・全体切替を含む判定資料|PMOが判断材料を統合。移行はbackend、復元はinfra、最終判断は人|合格|
|原因不明の本番障害|infraが初動。原因を断定せず、特定後に修正担当を移管|合格|
|利用者調査から操作試作・UAT・定着|業務定着を主成果物と仮定しbusinessが統合、操作試作はfrontend、人がUAT合否|合格（主成果物の仮定を明示）|
|法的最終判断とML学習|対象外・未分類と明示し、必要な専門担当とスコープ再定義へ渡す|合格|

再レビューの残課題: PMOの旧引継ぎと単独planスキルのJSON参照を修正。再確認で両方解消、生成物の鮮度検査も成功。
限界: 計画段階の自然言語試行であり、全モデルの再現率や実案件の品質を保証しない。実アプリ・クラウド・ユーザー端末は未検証。
